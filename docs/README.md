## 🚀 クイックスタート

1. [リリースページ](https://github.com/Eotel/garoon2gs/releases)から最新版をダウンロード
2. `.env`ファイルを設定（[設定方法](./garoon2gs/user_manual.md#設定方法)を参照）
3. `./garoon2gs`コマンドを実行
