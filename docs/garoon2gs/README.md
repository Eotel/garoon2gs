## 🚀 クイックスタート

1. 必要なファイルを準備
   - `.env` - 環境設定ファイル
   - `user_mapping.csv` - ユーザーマッピング
   - `sheet_mapping.csv` - シートマッピング
   - Google認証用JSONファイル

2. 実行
   ```bash
   ./garoon2gs
   ```

詳細は[ユーザーマニュアル](./user_manual.md)を参照してください。
